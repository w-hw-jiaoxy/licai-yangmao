# 理财羊毛记账本

手机端单文件记账小工具：记录短期理财 / 羊毛产品的本金、锁定期、到期日、预估收益，自动倒计时提醒到期赎回。

在线使用：https://w-hw-jiaoxy.github.io/licai-yangmao/

## 功能

- 到期日自动计算（购买日期 + 锁定期天数），输入时实时预览
- 到期倒计时：剩 X 天 / 今天到期 / 逾期 X 天，3 天内到期高亮提醒
- 年化收益率自动计算
- 一键「赎回」标记已到期，不用进编辑页
- 全部 / 持有中 / 已赎回筛选
- 「借款」类型：记录待还款（如微粒贷），与理财收益分开统计，同样享受到期倒计时提醒
- 导出 / 导入 JSON 备份（换手机迁移）

## 隐私

纯前端单文件 `index.html`，记录只保存在本机浏览器 localStorage，不上传到任何服务器。
